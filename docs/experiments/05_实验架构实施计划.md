# NavDP–MINCO Experiment Architecture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use test-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不启动真实仿真的前提下，交付可扩展、可测试、可生成分层示例结果的 NavDP–MINCO 实验工具链。

**Architecture:** `experiments` 使用端口与适配器结构。核心指标和数据契约不依赖仿真，编排器只依赖后端协议，mock 后端产生确定性数据并驱动与真实运行相同的记录、校验和分析链路。

**Tech Stack:** Python 3.10、NumPy、SciPy（可用时）、标准库 csv/json/threading/argparse、pytest。
